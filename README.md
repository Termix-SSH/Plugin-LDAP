## Overview

LDAP lets people sign in to Termix with their LDAP or Active Directory username and password.

Read the [docs](https://docs.termix.site/plugins/ldap) to set it up and use it.

<br />

## Features

- Sign in against LDAP or Active Directory
- More than one directory, each with its own login button
- LDAPS for encrypted connections
- Make members of an admin group Termix admins

## Support

Bugs and ideas for LDAP go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-LDAP/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-LDAP/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
